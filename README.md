# 📍 Encuesta con Geolocalización

[![GitHub Pages](https://img.shields.io/badge/GitHub-Pages-blue.svg)](https://tu-usuario.github.io/encuesta-geolocalizacion/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Sistema de encuestas que valida la ubicación GPS de los usuarios antes de permitirles responder.

## ✨ Características

- 📍 **Validación GPS obligatoria** - Los usuarios deben confirmar su ubicación
- 🔒 **Ubicación bloqueada** - Una vez confirmada, no se puede modificar
- 📋 **Google Forms integrado** - Muestra la encuesta en iframe
- ⏱️ **Doble timestamp** - Registra captura y envío de ubicación
- 📊 **CSV automático** - Genera y actualiza archivo CSV local
- ♾️ **Sin límite** - Acepta todas las respuestas
- 🎨 **Diseño responsive** - Funciona en todos los dispositivos
